# Rolling Two-Week Staffing Schedule (Excel)

This repo contains a practical Excel setup for maintaining a **master two-week staffing template** and automatically generating a **rolling two-week dated calendar**.

## Files

- `docs/excel-rolling-two-week-setup.md` — step-by-step setup instructions with formulas.
- `excel/RefreshRollingSchedule.bas` — optional VBA macro to hard-paste values from template to the rolling calendar.

## Quick start

1. Open Excel and create a workbook with two sheets:
   - `MasterTemplate`
   - `RollingCalendar`
2. Follow the setup guide in `docs/excel-rolling-two-week-setup.md`.
3. (Optional) Import `excel/RefreshRollingSchedule.bas` if you want a one-click refresh button.
4. See the guide section **"Implement `RefreshRollingSchedule.bas` in Excel (step-by-step)"** for exact setup, button wiring, and troubleshooting.
